# 모듈러 선반 3D 플래너

브라우저에서 설치 없이 선반의 치수·마감·서랍/도어 모듈을 바꾸며 **실시간 3D 확인 + 부품 목록(BOM) + 견적**을 얻는 웹 컨피규레이터.
(마그네틱 행거, 인테리어 모듈, 가구 커스터마이징 등 3D 계산기류 외주를 겨냥한 포트폴리오)

## 기능
- React Three Fiber 기반 3D 렌더링 (회전/줌, 그림자)
- 가로·세로·깊이·단 수 슬라이더 → 칸 수/칸 내부 치수 자동 계산 (파라메트릭)
- 칸 단위 **스냅 배치**: 서랍/도어 모듈 선택 후 칸에 호버 → 하이라이트 → 클릭
- 치수가 줄어 사라지는 칸의 모듈은 자동 정리
- BOM(세로 패널, 선반, 후면, 모듈, 커넥터) 수량·규격·금액 실시간 산출, 견적 텍스트 복사

## 실행
```bash
npm install
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드 (Vercel에 그대로 배포 가능)
```

## 구조
- `src/store.ts` 상태(zustand)와 칸 치수 계산
- `src/bom.ts` 부품/견적 계산 (단가 상수는 파일 상단)
- `src/Shelf.tsx` 3D 모델 생성
- `src/Panel.tsx` 컨트롤 패널

## 확장 포인트 (외주 시 제안)
GLTF/CAD 모델 로딩, 부품 자유 드래그, 벽면 치수 입력, 견적서 PDF, 발주 연동.
